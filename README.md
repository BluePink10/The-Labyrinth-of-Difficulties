# 🗝️ Вор и Мирные — веб-версия

Онлайн-мультиплеер на 3 игроков (1 вор + 2 мирных жителя). Каждый заходит
со своего телефона/компьютера по коду комнаты, роль видна только ему самому —
никому не нужно "отворачиваться", как в локальной версии.

## Структура проекта

```
thief-game/
├── app.py
├── requirements.txt
├── Dockerfile
├── README.md
└── static/
    ├── index.html
    ├── style.css
    ├── client.js
    └── assets/
        ├── stone.png       — текстура стен
        ├── chest.png       — сундук
        ├── diamond.png     — алмаз
        ├── 1.png ... 8.png — 8 персонажей на выбор в лобби
        ├── 9.png           — свиток "мирный" (экран роли)
        └── 10.png          — свиток "вор" (экран роли)
```

Все картинки — твои оригинальные (персонажи на выбор, текстура камня для стен,
сундук, алмаз, и два "свитка" с ролями). Я их уменьшил и сжал (с ~9.7 МБ до
~1.6 МБ суммарно), чтобы игра быстро грузилась на телефоне у подружек —
визуально они не отличаются от оригинала.

## Как задеплоить на Render.com (бесплатно)

1. Залей всю папку `thief-game` (со всеми подпапками, включая `static/assets/`)
   в репозиторий на GitHub — см. инструкцию ниже.
2. На render.com → **New** → **Web Service** → выбери репозиторий.
3. Runtime определится автоматически как **Docker** (по `Dockerfile` в корне).
   Instance Type — **Free**.
4. Нажми **Create Web Service**, дождись сборки (2-4 минуты) — получишь ссылку
   вида `https://thief-game-xxxx.onrender.com`.
5. Открой ссылку → «Создать комнату» → отправь ссылку и код подружкам.

Бесплатный тариф Render засыпает после ~15 минут без запросов и просыпается
~30-60 секунд при следующем заходе — открой ссылку заранее перед игрой.

## Как задеплоить на Hugging Face Spaces (нужен план PRO)

Создание Docker-space на личном аккаунте HF сейчас требует план PRO
($9/мес) — само CPU-железо при этом бесплатное. Если это ок:

1. huggingface.co/new-space → SDK = **Docker** → заполни поля → Create Space.
2. Залей туда все файлы той же структурой, что выше.
3. Space соберётся сам за пару минут, ссылка вида
   `https://юзернейм-название.hf.space`.

## Локальный запуск (для проверки перед деплоем)

```bash
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 7860
```

Открой `http://localhost:7860` в нескольких вкладках браузера, чтобы
проверить игру за всех троих игроков сразу.

## Важные технические детали

- **Один WebSocket-канал на комнату.** Сервер — единственный источник истины:
  считает движение, столкновения со стенами, сбор алмазов, открытие сундуков
  и кражи. Клиент только отправляет ввод (нажатые клавиши / джойстик) и
  рисует то, что прислал сервер.
- **Роль передаётся приватно** — сообщением `game_start`, которое сервер
  отправляет только конкретному игроку через его сокет.
- Аватарки — это просто идентификаторы `"1"`...`"8"`, привязанные к файлам
  `static/assets/<id>.png`. Если захочешь заменить картинки — положи новые
  PNG с теми же именами (1.png...8.png), менять код не нужно. Так же можно
  заменить `9.png`/`10.png` (экран роли), `chest.png`, `diamond.png` и
  `stone.png` (текстура стен).

## Настройки, которые можно быстро поменять (в `app.py`)

| Константа | Что делает |
|---|---|
| `MAZE_W`, `MAZE_H` | размер лабиринта на этаже |
| `NUM_LEVELS` | количество этажей |
| `GAME_DURATION` | длительность раунда в секундах |
| `STEAL_COOLDOWN_MS` | перезарядка кражи у вора |
| `CHEST_OPEN_MS` | сколько держать кнопку, чтобы открыть сундук |

## Ограничение по игрокам

Комната рассчитана ровно на **3 игроков** (1 вор, 2 мирных). Четвёртый
подключившийся получит сообщение "комната заполнена".
